# booth-versions

BOOTH で配布しているツールの最新バージョン情報です。各ツールのエディタ拡張が `versions.json` を読み、手元のバージョンより新しければインスペクターに BOOTH へのリンクを表示します。

- `id`: ツールの識別名（ツール側のコードと一致させる）
- `version`: 最新版の番号（`0.4.2` の形。先頭の `v` は付けても付けなくてもよい）
- `url`: 新しい版を案内する BOOTH のページ

新しい版を出したら、ここの `version`（必要なら `url`）を書き換えてください。反映まで数分かかることがあります。
